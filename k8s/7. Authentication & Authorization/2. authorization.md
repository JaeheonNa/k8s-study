### RBAC(Role Based Access Control)
##### Role vs Cluster Role
- kubernetes API에 접근할 때 Service Account의 token을 사용하여 접근할 수 있음.
- 이 때, Service Account에 바인딩 된 '역할'에 따라 kubernetes API에 할 수 있는 요청이 제한 됨.
- Role은 Namespace 단위로 관리되는 object에 대한 권한이고,
- ClusterRole은 Cluster 단위로 관리되는 object에 대한 권한임.
- Role과 ClusterRole은 Service Account가 가질 수 있음. (RoleBinding이나 ClusterRoleBinding로 매핑.)
- 권한에는 **get, list, create, update, patch, watch, delete** 등이 있음.


    1. Role - RoleBinding - Service Account
    2. ClusterRole - ClusterRoleBinding - Service Account
    3. ClusterRole - RoleBinding - Service Account

- 3번 case의 경우 ClusterRole는 RoleBinding이 속한 Namespace 내 object들에 대한 권한임.
- 결국 1번 case와 같은 권한인 건데, 이렇게 사용하는 이유는, 재사용성 때문임. 다른 각기 다른 Namespace 내 Service Account들이 각각의 Namespace 내 object들에 대해 모두 같은 권한을 가져야할 때 사용.

> [참고] \
> Cluster 단위로 관리되는 objects: Node, PV, Namespace, ClusterRole, ClusterRoleBinding \
> Namespace 단위로 관리되는 objects: Pod, Service, ServiceAccount, Role, RoleBinding

### 예제1. 자신의 Namespace 내 Pod들만 조회할 수 있는 Service Account(default)
- Namespace


    apiVersion: v1
    kind: Namespace
    metadata:
        name: namespace-01

- Role
 

    apiVersion: rbac.authorization.k8s.io/v1
    kind: Role
    metadata:
        name: role-01
        namespace: namespace-01
    rules:
    - apiGroups: [""]
      verbs: ["get", "list"]
      resources: ["pods"]

- RoleBinding
 

    apiVersion: rbac.authorization.k8s.io/v1
    kind: RoleBinding
    metadata:
        name: roleBinding-01
        namespace: namespace-01
    roleRef:
        apiGroup: rbac.authorization.k8s.io
        kind: Role
        name: role-01
    subjects:
    - kind: ServiceAccount
      name: default
      namespace: namespace-01

### 예제2. 해당 cluster 내 모든 object들에 대한 모든 권한을 가진 Service Account
- Namespace


    apiVersion: v1
    kind: Namespace
    metadata:
        name: namespace-02

- Service Account


    apiVersion: v1
    kind: ServiceAccount
    metadata:
        name: serviceAccount-01
        namespace: namespace-02


- ClusterRole
 

    apiVersion: rbac.authorization.k8s.io/v1
    kind: ClusterRole
    metadata:
        name: clusterRole-01
    rules:
    - apiGroups: ["*"]
      verbs: ["*"]
      resources: ["*"]

- ClusterRoleBinding
 

    apiVersion: rbac.authorization.k8s.io/v1
    kind: ClusterRoleBinding
    metadata:
        name: clusterRoleBinding-01
        namespace: namespace-02
    roleRef:
        apiGroup: rbac.authorization.k8s.io
        kind: ClusterRole
        name: clusterRole-01
    subjects:
    - kind: ServiceAccount
      name: serviceAccount-01
      namespace: namespace-02
