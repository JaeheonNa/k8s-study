### HPA(Horizontal Pod Autoscaler)
- Pod의 수를 조절하는 Scaler. Scale out/in 수행.
- Master Node의 Controller Manager Pod에 위치하고 있음.
- kube-apiserver를 통해 모든 Node의 Pod들의 CPU/Memory 사용량을 15초 간격으로 체크함.
- Pod의 자원 사용량을 모니터링하다가, 자원 사용량이 임계치를 넘어서면, Controller(ReplicaSet)의 replicas를 늘려줌.
- 장애 상황에서 Pod를 늘려주는 역할을 하기 때문에 기동이 빠른 App 대상으로 하는 게 좋음.
- StatefulSet에 HPA를 걸게 되면, Scale out할 때, 어떤 Pod를 Scale out해야할 지 HPA 입장에서는 알 수 없음.
- 따라서 Stateless한 ReplicaSet에만 HPA를 거는 것을 권장함.
- HPA를 설치하려면 Metrics Server를 설치해야 함.
> [Metrics Server 설치] \
> kubectl apply -f https://raw.githubusercontent.com/k8s-1pro/install/main/ground/k8s-1.27/metrics-server-0.6.3/metrics-server.yaml \
> cd metrics-server \
> kubectl apply -f deploy/kubernetes/ \
> [설치 확인] \
> kubectl get apiservices | egrep metrics \
> [메트릭 값 확인] \
> kubectl top node


    apiVersion: apps/v1
    kind: Deployment
    metadata:
     name: stateless-cpu1
    spec:
     selector:
       matchLabels:
          resource: cpu # resource: memory
     replicas: 2
     template:
       metadata:
         labels:
           resource: cpu # resource: memory
       spec:
         containers:
         - name: container
           image: kubetm/app:v1
           resources:
             requests:
               cpu: 10m # memory: 10Mi
             limits:
               cpu: 20m # memory: 20Mi

    apiVersion: v1
    kind: Service
    metadata:
     name: stateless-svc1
    spec:
     selector:
        resource: cpu # resource: memory
     ports:
       - port: 8080
         targetPort: 8080
         nodePort: 30001
     type: NodePort

    apiVersion: autoscaling/v2
    kind: HorizontalPodAutoscaler
    metadata:
      name: hpa-resource-cpu
    spec:
      maxReplicas: 10
      minReplicas: 2
      scaleTargetRef:
        apiVersion: apps/v1
        kind: Deployment
        name: stateless-cpu1
      metrics:
      - type: Resource 
        resource:
          name: cpu # name: memory
          target:
            type: Utilization # type: AverageValue
            averageUtilization: 50 # averageValue: 5Mi


> [HPA 조회] \
> kubectl get hpa -w

### VPA(Vertical Pod Autoscaler)
- Pod가 사용하는 자원을 조절하는 Scaler. Scale up/down 수행.
- Pod의 자원 사용량을 모니터링 하다가, 자원 사용량이 임계치를 넘으면, 해당 Pod를 Restart시키면서 자원 사용량을 늘려줌.
- Stateful App(StatefulSet) 대상임.
- 한 controller에 HPA와 VPA를 둘다 연결하면 안 됨.


    ReplicaSet - HPA
    StatefulSet - VPA


### CA(Cluster Autoscaler)
- Node의 수를 조절하는 scaler. 
- 이미 생성된 Pod들이 Node(Local Node이든, Cloud Node이든)의 자원을 모두 사용 중이며, 동시에 새 Pod를 생성해야할 때, Scheduler가 CA에게 Node 할당을 요청함.
- AWS, GCP, AZURE 등 cloud provider와 연결돼 있는 CA는 cloud provider에게 Node 할당을 요청함.
- Node가 새로 할당되면, Scheduler는 새 Pod를 해당 Node에 생성함.
- 반대로 기존 Node의 자원에 여유가 생기면 scheduler가 이를 감지하고 CA에게 Node 반납을 요청하고, Node가 회수되면, 해당 Node에 있던 Pod를 기존 Node로 옮김.
